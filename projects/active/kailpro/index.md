# KailPro — Project Card
**SaaS App untuk Pemancing Malaysia**

---

## Project Overview

**KailPro** adalah SaaS mobile-first app untuk komuniti pemancing Malaysia. Core value: log perjalanan mancing (GPS path), simpan lubuk ikan, port/parking spot, dan real-time data (pasang surut, cuaca laut, kawasan larangan). Free tier untuk penggunaan peribadi, paid tier untuk akses community data dan premium features.

### Key Stats
- **Status**: Brainstorm / Pre-Planning
- **Dimulakan**: 2026-08-22
- **Owner**: Abam Zue (Zurairi)
- **Target Market**: Pemancing Malaysia (sungai + laut + pesisiran)
- **Model**: SaaS — Free + Paid tiers

---

## Stack (Cadangan)

| Layer | Teknologi |
|---|---|
| Frontend | React PWA (offline-capable) |
| Backend | Supabase (Auth, DB, Storage, Realtime) |
| Maps | Leaflet.js + OpenStreetMap / Mapbox |
| Real-time data | JUPEM Tide API, OpenWeatherMap Marine |
| Geofencing | Turf.js (kawasan larangan polygon) |
| Payments | Toyyibpay (Malaysia) |
| Hosting | Vercel / Netlify |
